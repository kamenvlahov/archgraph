# archgraph

Нодова карта на архитектурата на кода, в стила на ComfyUI. Разширение за VS Code, а по-късно и за PhpStorm/JetBrains.

Кодът се чете файл по файл, а архитектурата е граф, който никой не вижда. archgraph чете проекта и показва този граф: контролери, сървиси, репозиторита, интерфейси и фактори, всеки като нод с **входове и изходи**. Изходите са параметрите и типовете, които връща, с пълната им структура.

```
┌─ OrderController ────────┐        ┌─ «interface» OrderServiceInterface ─┐
│ handle                   │        │ place                               │
│  ● request: Request      │        │  ● dto: PlaceOrderDto ──┐           │
│               Response ● │──────▶ │      ├ customerId: int  │           │
└──────────────────────────┘        │      └ items: Item[]    │           │
                                    │                Order ●  │           │
                                    └─────────────────────────────────────┘
```

## Какво прави

- **Чете** PHP, Node (JS/TS) и Python.
- **Разпознава роли и патерни** по framework: Controller, Service, Repository, Factory, Interface, DTO и Entity.
- **Показва нодове с портове.** Методите са редове, параметрите са входове, а типът, който връщат, е изход. Типовете са оцветени като в ComfyUI.
- **Подрежда графа сам** и показва само процеса, който те интересува: route → controller → service → repository.
- **Обновява се** при всяка промяна на кода.
- **Клик върху нод** отваря файла на точния ред в редактора.
- **Шаблони на патерни.** Командата „правим Factory“ добавя празни нодове, които попълваш ти или AI.
- **План за AI.** Маркираш нодове и получаваш конкретен план със засегнатите файлове, новите класове и правилата на архитектурата. Има и MCP сървър, през който AI агентът пита графа директно.

Кодът остава единственият източник на истината. archgraph само показва и планира, а промените се правят в редактора.

## Използване

Изисква Node 24 и pnpm (`corepack enable`). Няма build стъпка.

```sh
pnpm install
pnpm archgraph scan ~/projects/shop -o graph.json
# archgraph: 156 файла (node 96, php 60) → 47 нода, 192 метода, 360 порта (97% без тип), 42 ребра за 0.3 s
```

- В git хранилище файловете идват от `git ls-files`, така че `.gitignore` се спазва.
- По подразбиране се пропускат `vendor`, `node_modules`, `.venv`, `venv`, `dist`, `build`, `*.min.js`, `*.d.ts` и файлове над 1 MB.
- `--exclude` (`-x`) добавя още: `-x 'backend-*' -x 'src/legacy/**'`.
- Два класа с едно и също пълно име остават и двата, с таг `duplicate`.

### План за промяна

```sh
pnpm archgraph plan ~/projects/shop -t "Добави отстъпки по код" -n OrderService#place -n PlaceOrderDto
```

Markdown за AI агент:

- кодът на засегнатите методи;
- кой ги вика и кого викат;
- как са свързани класовете (кой ги създава, какво имплементират, какво получават), т.е. образец за нови класове;
- полетата на типовете в сигнатурите;
- редът на промените.

Същото е и MCP инструментът `plan`.

### Точни ребра (SCIP)

Без нищо допълнително `calls` са по евристика (`confidence: inferred`). Ако е инсталиран SCIP индексатор за езика, archgraph го пуска и извикванията, които той разпознава, стават `exact`. Останалите остават `inferred`.

```sh
npm i -g @sourcegraph/scip-typescript @sourcegraph/scip-python
```

- Търсят се в `PATH` и до `node`.
- За TypeScript трябват инсталирани пакети (`node_modules`), иначе типовете от библиотеките са `any` и SCIP мълчи за тях.
- PHP засега е само по евристика.
- `--no-scip` пропуска индексаторите. На ComfyUI сканирането е 4 s вместо 70 s.

### Интерфейс

```sh
pnpm ui                                   # build на packages/ui
pnpm archgraph serve ~/projects/shop      # http://127.0.0.1:8790
```

Вляво са ендпойнтите. Избраният показва процеса си отляво надясно като нодове: роля, методи с параметри и резултат, разгъваеми DTO-та. Клик върху нод го фокусира и показва всичко за него. Сървърът слуша само локално.

### MCP сървър

За Claude Code и всеки MCP клиент. Инструменти: `trace`, `dependents`, `describe_node`, `find_by_role`, `plan`, `rescan`. Отговорите са кратък текст с `file:line`.

```sh
claude mcp add archgraph -s user -- node ~/projects/archgraph/apps/mcp/src/main.ts
```

- Проектът е текущата папка на клиента или `project` в заявката.
- Графът се сканира при първата заявка и се пази в паметта до `rescan`.
- SCIP е изключен по подразбиране, защото на голям проект първото сканиране става минута. Пуска се с `--scip`.
